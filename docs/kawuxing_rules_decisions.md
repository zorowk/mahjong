# 孝感卡五星规则决策：`xiaogan-kawuxing-1.0`

来源基线：`rules/1.md`。该版本只编码本文明确列出的状态与事件语义；未实现的计分番型不应被当作已支持。

## 已编码

| 规则 | 引擎语义 |
| --- | --- |
| 三人局 | `GAME_START` 未指定人数时初始化为 3 人。 |
| 牌集 | 筒、条各 1–9，加中发白，共 21 种牌、84 张；无万和风牌。 |
| 吃 | 不产生 `Chi` 事件；规则清单不包含吃。 |
| 碰 | `PENG` 取用上一张弃牌，手中移除两张同牌，形成公开副露并由碰牌者打出。 |
| 暗杠 | `GANG Kind=Concealed` 移除四张暗手牌，进入 `SupplementDraw`。 |
| 直杠 | `GANG Kind=Exposed` 取用上一张弃牌，移除三张暗手牌，形成公开杠。 |
| 蓄杠 | `GANG Kind=Added` 将已有碰牌加上手中第四张，升级为加杠。 |
| 补牌 | 杠后状态为 `SupplementDraw`；下一条 `DRAW` 是事实记录的补牌，不重新随机。 |
| 杠上杠 | 首杠倍率为 1；上一轮为杠后补牌、打出、再杠时倍率乘 2。每次杠将自己的倍率记录到 `KongChain.Payments`，不覆盖旧杠。 |

# 孝感卡五星规则决策：`xiaogan-kawuxing-1.0`

来源基线：`rules/1.md`。该版本只编码本文明确列出的状态与事件语义；未实现的计分番型不应被当作已支持。

## 已编码

| 规则 | 引擎语义 |
| --- | --- |
| 三人局 | `GAME_START` 未指定人数时初始化为 3 人。 |
| 牌集 | 筒、条各 1–9，加中发白，共 21 种牌、84 张；无万和风牌。 |
| 吃 | 不产生 `Chi` 事件；规则清单不包含吃。 |
| 碰 | `PENG` 取用上一张弃牌，手中移除两张同牌，形成公开副露并由碰牌者打出。 |
| 暗杠 | `GANG Kind=Concealed` 移除四张暗手牌，进入 `SupplementDraw`。 |
| 直杠 | `GANG Kind=Exposed` 取用上一张弃牌，移除三张暗手牌，形成公开杠。 |
| 蓄杠 | `GANG Kind=Added` 将已有碰牌加上手中第四张，升级为加杠。 |
| 补牌 | 杠后状态为 `SupplementDraw`；下一条 `DRAW` 是事实记录的补牌，不重新随机。 |
| 杠上杠 | 首杠倍率为 1；上一轮为杠后补牌、打出、再杠时倍率乘 2。每次杠将自己的倍率记录到 `KongChain.Payments`，不覆盖旧杠。 |

## 2026-10-10 新版本：`xiaogan-kawuxing-1.1`

以上记录是 1.0 的历史边界，不回写。新版本在 `Rules.wl` 单一 GameEngine 内补齐以下行为：

- 完整 84 张牌墙作为 GameStart 事实，发牌与摸牌必须匹配牌墙；庄家 14 张、闲家 13 张。普通摸牌取墙头、杠补取墙尾，这是本版本固定约定。
- 每张弃牌等待其他两人各声明一次 Hu/Peng/Gang/Pass；先收齐响应再执行，胡优先，允许双响。碰/直杠消耗牌河最后一张。
- 蓄杠先开启抢杠窗口；有人胡则取消升级和本次杠费，保留原碰，取走第四张。暗杠/直杠不开放抢杠窗口。
- 计分选合法分解中的最高倍数组合，不同时叠加七对与标准牌型。七对 4、龙七对 8、双龙七对 16；兼容番型累乘。支持碰碰胡、三元牌、清一色、手抓一、明暗四归一、卡五星、亮倒、杠开/杠炮和抢杠。
- 小胡倍率 1 只能自摸；倍率大于 1 可接炮。底分为 1、无封顶，这是验证结算的原型单位，不是现金规则确认。
- 暗杠其他两人各付 2，蓄杠各付 1，直杠弃牌者付 2；连续杠倍率 1、2、4…，逐笔累计。流局/杠炮保留已有杠费，账目零和。
- 单胡下局由赢家坐庄，双响由弃牌/抢杠来源玩家坐庄，流局庄家不变。

### 尚待确认的原型约定

3. 未给出三龙七对倍率，不推导为 32。只有未定义分解时 `WinScore` 返回 `UndefinedScoring`，不会生成合法 Hu；如存在标准牌型可评分分解则按该分解评分。
4. 开局连续发牌、庄家的最后一张作为初始自摸牌、同级碰杠就近优先属于本版本事件协议。正式外部牌谱需匹配此协议或使用新规则版本适配，不能伪装成所有地方玩法通用规则。

上述约定已编码但不代表负责人已确认；如改变须新增版本，不能改写 1.1 历史含义。
